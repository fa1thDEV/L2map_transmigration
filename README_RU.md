# UNR Dependency & Downporting Toolkit v1.7 (Русская документация)

Комплексный автономный инструментарий на Python для анализа, даунпорта, извлечения ресурсов, сравнения и трансмиграции карт (`.unr`) Lineage 2 (Unreal Engine 2), а также их статических моделей (`.usx`) и текстур (`.utx`).

---

## 🌟 Нововведения в версии 1.7

### 1. Автономный изолятор пакетов (1 файл на класс)
- **1 файл на класс**: Автоматически объединяет все необходимые карте 3D-модели в `Map_{СЕКТОР}_S.usx`, а все текстуры, шейдеры и карты высот — в `Map_{СЕКТОР}_T.utx`.
- **Перенаправление ссылок в `.unr`**: Модифицирует таблицу импорта (`ImportTable`) карты, перенаправляя внешние ссылки на созданные мастер-пакеты.
- **Полное отсутствие конфликтов**: Карту можно установить в любой клиент Lineage 2 без перезаписи стандартных пакетов (`Goddard_S`, `Aden_S`, `Giran_Village_S` и т.д.) и без риска повреждения оригинального клиента.
- **Понижение классов и адаптация под хроники**: Автоматически конвертирует заголовки пакетов под целевые хроники (C4, Interlude, H5, Classic) и заменяет несовместимые современные классы движка на базовые (`Spotlight` $\rightarrow$ `Light`, `AmbientSoundWObject` $\rightarrow$ `AmbientSound`, `DynamicProjector` $\rightarrow$ `Projector`).

### 2. Полная локализация на Английский и Русский языки
- Переключение языка в 1 клик прямо в заголовке окна: `[ 🇷🇺 Русский ]` / `[ 🇺🇸 English ]`.
- Все 10 вкладок, таблицы, метрики, диалоговые окна и отчеты переведены на русский язык с использованием профессиональной терминологии моддинга Lineage 2.

### 3. Сравнение карт между хрониками (Diff)
- Попарное сравнительное сопоставление двух файлов `.unr` с подсчетом дельты акторов, новых классов, добавленных пакетов и генерацией отчета в формате Markdown.

### 4. Встроенный экстрактор текстур UTX
- Извлечение текстур DXT1, DXT3, DXT5, RGBA8 и G16 напрямую в форматы `.dds` и `.png` без использования сторонних утилит.

### 5. Инспектор ландшафта и акторов
- Точный учет карты высот (`TerrainInfo`), коэффициентов масштабирования, а также количества размещенных на карте 3D-моделей и акторов.

## 🖥️ Использование графического интерфейса (GUI)

Запустите файл `run_gui.bat`:

1. **Файл карты (.UNR):** Выберите карту, которую необходимо перенести или проанализировать.
2. **Корень клиента L2:** Путь к папке клиента Lineage 2 (по умолчанию `E:\EndlessWar-proyecto\2-Juego`).
3. **Папка назначения:** Папка для сохранения результатов, отчетов и экспортированных пакетов.
4. **Переключение языка:** Кнопка в правом верхнем углу переключает весь интерфейс между **English** и **Русский**.

### Вкладки приложения:
* **📊 Сводка и метрики:** Общие размеры, версии движка и статистика пакетов.
* **📦 Требуемые пакеты:** Список всех пакетов `.usx`, `.utx`, `.uax` со статусом наличия в клиенте.
* **🎨 Модели и текстуры:** Полный перечень всех используемых 3D-моделей и материалов.
* **🏔️ Ландшафт и акторы:** Текстура карты высот, масштаб ландшафта и статистика по моделям.
* **🖼️ Экстрактор UTX:** Просмотр текстур внутри любого `.utx` и пакетный экспорт в DDS / PNG.
* **⚡ Оптимизация текстур:** Пакетное уменьшение текстур до 1024x1024 или 512x512 с выравниванием кратно двум.
* **🛡️ Валидатор хроник:** Проверка совместимости с хрониками C4, Interlude или High Five.
* **🔄 Сравнение карт (Diff):** Сравнение двух карт между собой с выявлением новых акторов и пакетов.
* **📦 Автономный изолятор (1/Класс):** Создание автономного комплекта из 3 файлов (`.unr`, `.usx`, `.utx`) для моментальной установки на целевой сервер/клиент.
* **📜 Журнал событий:** Детальный лог операций.

## 💻 Использование через командную строку (CLI)

```bash
# 1. Автономная изоляция карты под Interlude (1 файл на класс):
python cli.py -u "Maps\22_22.unr" --isolate --target-chronicle interlude

# 2. Анализ карты с проверкой совместимости под C4 и инспекцией ландшафта:
python cli.py -u "Maps\11_21.unr" --check-compat c4 --inspect-terrain

# 3. Экспорт всех зависимостей карты в отдельную папку:
python cli.py -u "Maps\11_21.unr" --copy --output "Export_11_21"

# 4. Извлечение текстур из пакета UTX напрямую в DDS и PNG:
python cli.py --extract-utx "Textures\T_texture.utx" --output "Extracted_Textures"

# 5. Сравнение двух карт разных хроник:
python cli.py -u "Mapas\c6\22_22.unr" --compare "Mapas\samurai\22_22.unr"
```
